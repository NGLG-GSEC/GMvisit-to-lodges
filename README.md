# Επισκέψεις Στοών & Εκπρόσωποι

Εφαρμογή της Μεγάλης Καγκελαρίας της Εθνικής Μεγάλης Στοάς της Ελλάδος για τον προγραμματισμό των επισκέψεων στις Στοές και τον ορισμό εκπροσώπων της Μεγάλης Στοάς.

## Λειτουργίες

- **Ημερολόγιο:** οι επισκέψεις ομαδοποιούνται ανά μήνα, με Στοά, αριθμό, τόπο, Επαρχία και εκπρόσωπο. Φίλτρα ανά Επαρχία, ανά εκπρόσωπο και για επισκέψεις χωρίς εκπρόσωπο.
- **Στοές:** το Μητρώο των Στοών της ΕΜΣτΕ. Με τον αριθμό της Στοάς συμπληρώνονται αυτόματα το όνομα και η Επαρχία.
- **Εκπρόσωποι:** όνομα, επώνυμο, αξίωμα και έτος. Ο βαθμός (Σεβάσμιος, Λίαν Σεβάσμιος, Πανσεβάσμιος, Σεβασμιώτατος Αδ.) προκύπτει από το αξίωμα μέσω ρυθμιζόμενου πίνακα.
- **Επαρχίες:** τα email των Γραμματειών και κείμενο ειδοποίησης έτοιμο για αντιγραφή.

## Χρήση

Ανοίξτε το `index.html` σε browser ή ενεργοποιήστε το GitHub Pages για το repository.

Τα δεδομένα αποθηκεύονται **μόνο στον browser** όπου ανοίγει η σελίδα. Χρησιμοποιήστε την «Εξαγωγή αντιγράφου» για αντίγραφο ασφαλείας ή για μεταφορά σε άλλη συσκευή, και την «Επαναφορά από αντίγραφο» για να τα φορτώσετε.

Το `seed-data.js` περιέχει τα αρχικά δεδομένα (Στοές και Επαρχίες). Φορτώνονται μόνο την πρώτη φορά που ανοίγει η σελίδα σε έναν browser.
